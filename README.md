Wallet Generator GUI

A tkinter-based HD wallet generator supporting Bitcoin and Ethereum.
Creates BIP39 mnemonics, derives keys, and displays addresses.

Dependencies:
  - tkinter (standard library)
  - bip-utils (pip install bip-utils)

Usage:
  python wallet_generator_gui.py
